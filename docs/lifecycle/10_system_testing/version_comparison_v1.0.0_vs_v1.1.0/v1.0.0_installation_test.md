## 3. Instrucciones de Reproducción desde Cero (Entorno A — `v1.0.0`)

```powershell
git worktree add --detach ./env_a_v1_0_0 v1.0.0
cd ./env_a_v1_0_0/sisap-by-cenivra-—-sistema-de-información-clínica-y-gobernanza
npm ci
Copy-Item firebase-applet-config.json.example firebase-applet-config.json
$env:SISAP_DB_DIR = "$PWD\tmp_db_v1_0_0"
$env:SISAP_DB_FILE = "sisap_v1_0_0.sqlite3"
$env:SISAP_PORT = "18081"
node backend/src/cli/init-db.js
node backend/src/cli/seed-fixtures.js
node backend/src/cli/health.js
npm test
npm run lint
npm run build
node backend/src/server.js
```
